# Daniele Catanesi

**Systems, infrastructure and automation engineering**

I’m a systems and infrastructure engineer based in Switzerland, with more than 25 years of experience across enterprise infrastructure, identity and automation.

I build tools that make operational work easier to run, troubleshoot and maintain. PowerShell is a substantial part of that work; this profile also includes Go tooling and practical Linux and cloud infrastructure studies.

## Selected work

| Project | What it does |

| [IT-ToolBox](https://github.com/SingularVector/IT-ToolBox) | Reusable PowerShell tools for logging, validation, identity queries and infrastructure automation. |

## How I approach the work

I start with an operational problem and keep the scope deliberate. Useful logs, understandable failures, readable code and explicit dependencies matter as much as the successful run.

The repositories include both maintained tools and historical work. Check each project’s documentation for its current requirements, limitations and release status.
